# 立创EDA 原理图设计说明（AutoDoor）

> 用途：按本文档在立创EDA 中绘制原理图，再用**原理图 → 转 PCB** 功能生成 PCB。
> 所有网络（net）名与固件 `Core/main.h` 中的引脚宏一一对应，改线时两处同步改。

器件总表见 `设计文档.md` 第 1.4 节。本文档只讲**怎么连**。

## 0. 原理图分页规划

| 页 | 内容 |

## 1. P1 电源页

### 1.1 网络

| 网络名 | 说明 |
|---|---|
| `+5V` | 主电源（适配器 5 V/2 A 或 4 节 AA 电池盒 6 V 经降压） |
| `+5V_MOTOR` | **已作废**：原为"经限位开关后的电机供电"。本设计不装限位，L9110S 的 `VM` 直接接 `+5V`，这个网络不再需要 |
| `+3V3` | MCU 与逻辑电源 |
| `GND` | 数字地 |
| `GND_MOTOR` | 电机回流地，**单点汇聚到电源入口** |

### 1.2 元件

| 位号 | 型号 | 参数 | 说明 |
|---|---|---|---|
| J1 | DC 电源座 / XH2.54-2P | — | 5 V 输入 |
| C1 | 电解电容 | 470 µF / 16 V | 电源入口储能 |
| C2 | 陶瓷电容 | 100 nF | 入口高频去耦 |
| U1 | AMS1117-3.3 | SOT-223 | 5 V → 3.3 V |
| C3 | 电解电容 | 10 µF / 10 V | U1 输入 |
| C4, C5 | 陶瓷电容 | 100 nF, 10 µF | U1 输出 |
| D1 | SS34 | SMA | 输入反接保护（可选） |
| F1 | 自恢复保险丝 | 1.1 A / 6 V | 总电流保护（可选） |

### 1.3 关键规则

> **星形接地**：`GND_MOTOR` 与 `GND` 只在电源入口处**用一个 0 Ω 电阻或直接单点**连接。
> 电机的大电流回流绝不能流经 MCU 的地平面 —— 这是本设计最大的可靠性风险来源。

```
J1 ──┬── F1 ──┬── +5V ──────────────┬── U1 ── +3V3
     │        │                     │
    C1       C2                    (去耦网络)
     │        │
    GND ──────┴──── ★ 单点 ★ ──── GND_MOTOR ── L9110S PGND/电机
```

## 2. P2 MCU 最小系统页

### 2.1 元件

| 位号 | 型号 | 参数 | 说明 |
|---|---|---|---|
| U2 | STM32F103C8T6 | LQFP48 | 主控 |
| Y1 | 无源晶振 | 8 MHz | HSE |
| C6, C7 | 陶瓷电容 | 22 pF | 晶振负载电容 |
| R1 | 电阻 | 10 kΩ | NRST 上拉 |
| C8 | 陶瓷电容 | 100 nF | NRST 去耦 |
| C9–C12 | 陶瓷电容 | 100 nF ×4 | **每个 VDD 引脚一个** |
| C13 | 陶瓷电容 | 10 µF | VDD 体电容 |
| SW1 | 轻触按键 | — | 复位 |
| J2 | 排针 1×4 | 2.54 mm | SWD：3V3 / SWDIO / SWCLK / GND |
| J3 | 排针 1×3 | 2.54 mm | BOOT0 / BOOT1 跳线 |

### 2.2 网络连接

| 引脚 | 网络 | 说明 |
|---|---|---|
| PA13 | `SWDIO` | 接 J2，**不可复用** |
| PA14 | `SWCLK` | 接 J2，**不可复用** |
| NRST | `NRST` | R1 上拉 + C8 + SW1 |
| BOOT0 | `BOOT0` | 经 10 kΩ 下拉到 GND（正常运行） |
| BOOT1/PB2 | `BOOT1` | 经 10 kΩ 下拉 |
| PD0/PD1 | `OSC_IN` / `OSC_OUT` | Y1 + C6/C7 |

### 2.3 ⚠️ 规则

1. **每个 VDD 引脚配一个 100 nF**，位置尽量靠近引脚。省掉会随机复位。
2. **晶振走线尽量短，两侧包地**，C6/C7 紧贴 Y1 与 MCU。
3. **PA13/PA14 必须留作 SWD**，不要接任何外设。占用了就无法下载与调试。
4. VBAT 接 +3V3（本设计不用 RTC，但不要悬空）。

## 3. P3 电机页（**安全关键，最容易画错**）

### 3.1 限位开关（**本设计不装**；以下为作废资料）

**本设计不安装限位开关**，所以 P3 页上**没有 SW2/SW3、R2/R3、C14/C15**，
也没有 `+5V_MOTOR` 这个网络：L9110S 的 `VM` 直接接 `+5V`。
门的位置由**标定行程时间** `DOOR_TRAVEL_MS`（2000 ms）推算。

**如果以后真的要装回限位**，需要：

| 项 | 内容 |
|---|---|
| 元件 | 2 个 KW12-3 微动开关（或光电/霍尔开关）、2 个 10 kΩ 上拉到 `+3V3`、2 个 100 nF 到 GND |
| 接线 | `COM` → GND，`NO` → PA0（开门）/ PA1（关门），低有效 |
| 固件 | `.\tools\build.ps1 -WithLimits`（即 `-DAUTODOOR_NO_LIMITS=0`）：读 PA0/PA1、占 EXTI0/EXTI1、看门狗回到 5000 ms |

> 这一节剩下的内容是**当年接限位时的图纸资料**，保留下来供以后装回时参考。
> 其中"NC 触点串联切断 `+5V → VM`"这条硬件断电回路**已经作废**，
> 它在"门静止关闭时也被压住"这个前提下会把门锁死 —— 完整推理见
> `docs/接线图.md` 第 5 节（已标明作废）。**画图前先在那里选定方案。**

#### 断电回路（NC，两个串联）—— **已作废**

> ### ⚠️ 本小节已作废：本设计不装限位，也没有这条回路
>
> 两个 NC 串联意味着 **门静止在任一端时电机都没有供电**。而门静止关闭时关门限位
> **正是被压住的**（装了限位时软件也要求它被压住，否则 `Door_Init()` 判断不出门是关的），
> 于是 **NC 断开 → 没有 VM → 门永远开不了**。
>
> **串联 NC 只能切"过头"，不能切"到位"。** 要真正的硬件层，必须让断电开关在
> **电气限位之外**（例如 90° 给信号、95° 才断电）动作，也就是每个方向两个开关。
> 完整推理与两条出路见 `docs/接线图.md` 第 5 节。
>
> 下面这张图和"三个必须遵守的点"本身没有错，错的是**动作点**：它们描述的是
> "切过头"的正确做法，却被当成了"切到位"。

```
+5V ──┬──────────────────────────────────────────────┐
      │                                              │
      │   ┌──────────────┐    ┌──────────────┐       │
      └───┤ COM   NC ├───┴────┤ COM   NC ├───────────┴──▶ +5V_MOTOR ──▶ L9110S VM
          └──────────────┘    └──────────────┘
           SW2 开门限位          SW3 关门限位
          (KW12-3, NC)        (KW12-3, NC)
```

**三个必须遵守的点**：

| # | 规则 | 后果 |
|---|---|---|
| 1 | 断电回路**必须用 NC 触点** | NC 时所有失效（断线/损坏）都导向"断开"＝停车（fail-safe）；若这里用 NO，失效方向会变成"永不闭合"＝**保护完全失效** |
| 2 | **只切 VM（电机供电），不切 VCC（逻辑供电）** | 若连逻辑一起切，MCU 掉电，状态机无法记录"因限位停止"，串口也报不出来 |
| 3 | **绝不要串在 H 桥输出 OA/OB 上** | 电机电流会走 H 桥内部体二极管，换向瞬间可能直通短路，烧模块 |

#### 读回回路（NO，3.3 V 域）—— **仅 `-WithLimits` 时需要**

| 位号 | 连接 |
|---|---|
| R2 | 10 kΩ，`LIMIT_OPEN` 上拉到 **+3V3** |
| R3 | 10 kΩ，`LIMIT_CLOSE` 上拉到 **+3V3** |
| C14 | 100 nF，`LIMIT_OPEN` 到 GND（硬件消抖） |
| C15 | 100 nF，`LIMIT_CLOSE` 到 GND |

接线：`COM` 接 **GND**，`NO` 接 MCU 引脚（PA0 / PA1）。

**极性是"低有效"**（注意与断电回路相反）：

| 门体状态 | NO 触点 | MCU 引脚 |
|---|---|---|
| 离开限位 | 断开 | 上拉 → **高** |
| **到达限位** | 闭合 | 拉地 → **低** |

固件里 `Limit.c` 已按此配置 `activeLevel = 0U`（只在该变体里编译）。

> ⚠️ **代价（如实记录）**：NO 读回的**失效方向是"不到位"**。断线时引脚被上拉读高，
> 状态机以为门没到限位，会一直等到行程看门狗超时才报故障
> （`-WithLimits` 下是 5000 ms）。所以损失的是**诊断速度**。
>
> **但不要再顺着这条往下写"断电保护仍然有效"** —— 这句话原本依赖
> §3.1 那条 NC 断电回路，而**那条回路已作废**（会把门锁死，见 `docs/接线图.md`
> 第 5 节）。装了限位、用 `-WithLimits` 构建时，限位的作用**只有"到位信号 +
> EXTI 立即停机"**这一层软件保护，没有硬件断电层。
>
> 若要让"断线也报到位"，读回也得用 NC——那就必须解决 5 V / 3.3 V 电平问题
> （分压或电平转换），本设计为简洁起见没有采用。

#### ⚠️ 接线前必须用万用表确认（3 分钟，能省几小时）—— **仅在装限位时**

KW12-3 的脚位定义**不同批次可能不一致**。上电前用万用表通断档量：

1. 找出**哪两个脚在"不按"时导通** → 那就是 `COM` 和 `NC`
2. 第三个脚就是 `NO`
3. 按下手柄，确认 `COM`–`NC` 断开、`COM`–`NO` 导通

**如果量出来的极性与本文档相反，改接线或改 `Limit.c` 的 `activeLevel`，不要两个都不改。**

### 3.2 限位信号的软件侧（**仅 `-WithLimits`，供对照**）

| 项目 | 值 |
|---|---|
| 引脚 | 开门 `PA0`（EXTI0）、关门 `PA1`（EXTI1） |
| 中断优先级 | 抢占 **0**（最高，高于红外 2 与按键 3） |
| 触发沿 | 上升 + 下降（都要） |
| 有效电平 | **低**（`activeLevel = 0`） |
| 消抖窗口 | 25 ms |
| ISR 动作 | 记录边沿 + **立即 `Motor_EmergencyStop()`** |
| 状态机判据 | **只用电平**，不用边沿（上电即停在限位时没有跳变） |

> **默认构建（不装限位）里这一整张表都不存在**：没有 EXTI0/EXTI1，
> 也就没有"限位触发立即停机"这一层。`Limit_IsOpen()` / `Limit_IsClosed()`
> 改为按**电机方向 + 已走时间**推算（见 `Hardware/Limit/Limit.c`）。

### 3.3 电机驱动

| 位号 | 型号 | 说明 |
|---|---|---|
| U3 | L9110S 模块 | 双路 H 桥，本设计用 1 路 |
| M1 | 130 直流电机 | 额定 3–6 V，**配减速机构** |
| C16 | 电解 470 µF | VM 就近去耦 |
| C17 | 陶瓷 100 nF | 跨接 OA–OB，**抑制电刷火花** |
| D2 | SS34 | 跨接 OA–OB，续流（阴极对 VM） |

| L9110S 引脚 | 网络 | 说明 |
|---|---|---|
| VCC | +5V | 逻辑供电 |
| GND | GND | |
| VM | **`+5V`（直供）** | **不经过任何开关**：限位断电回路已取消（§3.1） |
| IA | `MOTOR_IA`（PA4） | 软件 PWM |
| IB | `MOTOR_IB`（PA5） | 方向 |
| OA / OB | 接 M1 | 电机两端 |

> **注意**：130 电机是**玩具电机**，额定 3–6 V。**绝不要接 12 V**，会烧。
> 5 V 直供（L9110S 压降 0.3–0.5 V）正好在额定区间内。

## 4. P4 输入输出页

### 4.1 按键与模拟红外（6 个）

全部接法相同：一端接 GND，另一端接 MCU 引脚 + **10 kΩ 上拉** + **100 nF 到 GND**。

| 位号 | 网络（引脚） | 功能 | 上拉 | 去抖 |
|---|---|---|---|---|
| SW4 | `KEY1`（PB5） | 启停系统 | R4 10 kΩ | C18 100 nF |
| SW5 | `KEY2`（PB6） | 切换模式 | R5 | C19 |
| SW6 | `KEY3`（PB7） | 手动开门 / 日志上翻 | R6 | C20 |
| SW7 | `KEY4`（PB8） | 手动关门 / 长按急停 | R7 | C21 |
| SW8 | `SENSOR_OUT`（**PB12**） | 模拟门外红外（进门） | R8 | C22 |
| SW9 | `SENSOR_IN`（**PB13**） | 模拟门内红外（出门） | R9 | C23 |

> **EXTI 编号约束**：所有输入引脚必须占**互不相同的编号**。
> **默认构建（不装限位）只有 6 路**：`PB5…PB8`（按键）→ EXTI5–8、
> `PB12/PB13`（传感器）→ EXTI12/13，互不重复 ✅。**PA0/PA1 空着不接。**
> 若改用 `-WithLimits`，则再加上 `PA0/PA1`（限位）→ EXTI0/1，共 8 路，同样互不重复 ✅。
>
> ⚠️ **传感器原来接 PB0/PB1，已经改掉。** 原因是 STM32F1 的 EXTI 线按**引脚编号**共用，
> 而 AFIO 每条线**只能选一个端口**：`Limit_Init()` 先占 EXTI0/EXTI1，`Sensor_Init()`
> 后跑、把两条线都抢走，于是**限位一个中断都没有**，而且全程没有任何报错。
> 现在 `main.h` 里有编译期断言，重复编号会直接编译失败；`Exti_ConfigPin()`
> 也会拒绝把已有线改映射到别的端口并在上电时打印冲突计数。
> **改引脚时不要绕过这两道检查。**（限位取消后 EXTI0/EXTI1 是空的，
> 但一旦用 `-WithLimits` 就立刻被占用，所以传感器留在 PB12/PB13 才是稳的。）

### 4.2 蜂鸣器

| 位号 | 型号 | 说明 |
|---|---|---|
| LS1 | **有源蜂鸣器**（带驱动板） | 3.3–5 V |
| R10 | 1 kΩ | 基极限流（若模块自带驱动则省略） |
| Q1 | S8050 NPN | 驱动（若模块无驱动级） |
| D3 | 1N4148 | 蜂鸣器续流 |

| 连接 | 网络 |
|---|---|
| 控制 | `BUZZER`（PB3） |
| 供电 | +5V |

> **PB3 复位后是 JTDO**，固件已调用 `App_JtagDisable()` 释放（**只关 JTAG，保留 SWD**）。
> 硬件上无需额外处理，但要知道这一点。

### 4.3 OLED 与 EEPROM（共用一条软件 I²C）

| 位号 | 型号 | I²C 地址 |
|---|---|---|
| U4 | 0.96" SSD1306 OLED 模块 | 0x78（7 位 0x3C） |
| U5 | AT24C32 模块 | 0xA0（7 位 0x50） |

| 网络 | 引脚 | 说明 |
|---|---|---|
| `I2C_SCL` | PB10 | 所有器件 SCL 并联 |
| `I2C_SDA` | PB11 | 所有器件 SDA 并联 |
| R11, R12 | 10 kΩ | **SCL、SDA 各一个上拉到 +3V3** |

> **上拉电阻必须有**。多数模块自带上拉，但**两个模块并联后阻值会减半**，
> 若通信不稳，去掉模块上的上拉只保留 R11/R12。

### 4.4 串口

| 位号 | 型号 | 说明 |
|---|---|---|
| J4 | 排针 1×4 | GND / TX / RX / 5V，接 USB-TTL（CH340） |

| 网络 | 引脚 | 接 J4 |
|---|---|---|
| `USART1_TX` | PA9 | 接 CH340 的 **RX** |
| `USART1_RX` | PA10 | 接 CH340 的 **TX** |

> TX/RX 必须**交叉**连接。

### 4.5 状态 LED（**必需，不是可选**）

这是需求里"LED 灯（系统状态指示）"的落点。

| 位号 | 连接 | 说明 |
|---|---|---|
| D4 | LED 红发红，阳极经 R13（1 kΩ）到 **PB4**，阴极到 GND | 状态指示，由 `Hardware/Led/StatusLed.c` 驱动 |

闪烁含义（`StatusLed.c` 的 6 种模式）：

| 门态 | 表现 |
|---|---|
| `IDLE` | 常灭 |
| `OPENING` | 常亮 |
| `OPEN` | **慢闪**（500 ms）—— 门开着，正在倒计时 |
| `CLOSING` / `REVERSING` | **快闪**（125 ms）—— 正在动，请勿靠近 |
| `STOPPED` | 双闪 —— 故障或急停，需处理 |
| `INIT` | 快速双闪 |

> **快闪与慢闪的区别是故意的**：站在门口的人最需要一眼分辨"门开着在倒计时"和"门正在动"。

> ⚠️ **`Core/main.h` 里还有一组 `LED_*`（PC13）宏，是遗留的未使用代码。**
> 驱动 PC13 心跳的 `led_init()` / `led_toggle()` 在重写 `Core/main.c` 时被删掉了，
> 现在没有任何代码引用它们。**请勿把状态 LED 接到 PC13 —— 它不会亮。**
> 该组宏的去留见设计文档第 12 节。

| `generated/bom.csv` | 元件清单（位号/数量/参数/封装/说明） |

**改了 `Core/main.h` 的引脚宏之后，务必重新运行**：

```powershell
python tools\gen-hardware.py
```

它会检查：每个固件引脚是否恰好被一个网络占用、有没有宏定义了却没接进原理图、
有没有哪个网络引用了不存在的宏。**不通过就说明原理图与固件已经不一致了。**
（本工具的引入过程见设计文档第 12 节 —— 它第一次运行就查出了一处真实的命名不一致。）

## 6. PCB 布局要点

| 项 | 要求 |
|---|---|
| 层数 | 2 层即可 |
| 尺寸 | 建议 80 × 60 mm |
| **电机大电流路径** | 走线加粗（≥ 1 mm），**回流不经过 MCU 地** |
| 地平面 | 底层尽量整片铺地；`GND` 与 `GND_MOTOR` 单点连接 |
| 晶振 | 紧贴 MCU，走线短，**包地** |
| 去耦电容 | 100 nF 紧贴对应 VDD 引脚 |
| 限位/按键接口 | 放在板边，方便接线（**限位不装**，只留按键/传感器） |
| 电机接口 | 与信号接口**物理分开**，不要并排 |
| 丝印 | 每个接口标注网络名，方便接线 |
| 测试点 | 至少留：+5V、+3V3、GND、`MOTOR_IA` |

## 7. 绘制完成后的自检清单

打板前逐项确认：

- [ ] **PA0/PA1 悬空**：限位已取消，这两脚在原理图上**不接任何网络**（保留为测试点/焊盘即可）
- [ ] L9110S 的 **`VCC` 与 `VM` 都直接接 `+5V`**，中间没有任何开关（限位断电回路已作废）
- [ ] `MOTOR_IA`/`MOTOR_IB` 接 PA4/PA5（不是 PA6/PA7）
- [ ] 所有 EXTI 引脚编号**互不相同**（默认构建只有按键 4 + 传感器 2 共 6 路）
- [ ] PA13/PA14 只接 SWD 排针
- [ ] 每个 VDD 都有 100 nF
- [ ] I²C 有上拉（R11/R12 或模块自带，注意并联阻值）
- [ ] 晶振有 22 pF ×2 且走线短
- [ ] 电机端子有 SS34 与 100 nF
- [ ] `GND` 与 `GND_MOTOR` 单点汇聚
- [ ] **状态 LED 接 PB4，不是 PC13**
- [ ] `tools/gen-hardware.py` 运行通过（无 PROBLEM）
- [ ] ERC（电气规则检查）无 error

> **若以后要加回限位**，再补上 §3.1 那三项（KW12-3 ×2、10 kΩ ×2 上拉、100 nF ×2），
> 并用 `-WithLimits` 构建：届时还需要检查
> - [ ] 限位读回用 **NO** 触点：`COM` 接 GND，`NO` 接 PA0/PA1 + 10 kΩ 上拉到 **+3V3**
> - [ ] 限位读回脚有 100 nF 到 GND（C14/C15）
> - [ ] 用万用表确认过脚位：`COM`–`NC` 不按时导通
> - [ ] 若要做硬件断电层，先读 `docs/接线图.md` 第 5 节（**串联 NC 只能切"过头"，不能切"到位"**）

## 8. 与固件不一致的已知项（如实记录）

| 项 | 状态 | 影响 |
|---|---|---|
| PA0/PA1（`LIMIT_OPEN`/`LIMIT_CLOSE`） | **限位已取消，两脚不接** | 位置按标定行程时间推算；要装回限位需 `-WithLimits` + §3.1 的元件 |
| PC13 的 `LED_*` 宏 | **遗留未使用**（原心跳功能已在重写 main.c 时移除） | 无影响；但**不要**把状态 LED 接到 PC13 |
| `Sensor` 为按键模拟 | 原理图用按键 | 真实红外（E18-D80NK）接线相同：OC 输出 + 上拉 |
| OLED 型号 | 真机和 Proteus 均使用 OLED12864 I2C（SSD1306-compatible） | 共用 PB10/PB11 软件 I2C |
| 蓝牙 USART2 | 未接 | PA2/PA3 预留 |
| RTC | 无 | 时间为开机相对值，由 PC 换算 |
